# 智能保险柜 · Android App

用 **Android Studio** 打开**本目录**（`android/`），不要打开仓库根目录。

## 快速开始

1. Android Studio → Open → 选择本文件夹  
2. Sync Gradle  
3. 连接真机运行（BLE 配网需要真机）

| 项 | 值 |
| --- | --- |
| 应用名 | 智能保险柜 |
| 包名 | `com.fingerprintlock.app` |
| 最低系统 | Android 8.0（API 26） |

完整硬件说明、固件烧录与 MQTT 协议见仓库根目录 [README.md](../README.md)。
